```
spotto-brandbook/
├── index.html          # Página principal del brandbook
├── css/

├── _config.yml         # Config de GitHub Pages
└── README.md
```

## Deploy en GitHub Pages

1. Subí los archivos a tu repo
2. Andá a **Settings → Pages**
3. En *Source*, seleccioná **Deploy from a branch**
4. Elegí la rama `main` y carpeta `/ (root)`
5. Guardá — en 1-2 minutos el sitio está live
